# Schema Kit — registro delle versioni

## 1.0.0 — 17 agosto 2026

Prima base operativa derivata dai quattro schemi di S1 Starlink e S2 Palantir.

- introdotto il telaio Nunjucks componibile;
- separati gli stili infrastrutturali dalla geometria specifica;
- introdotto un runtime cancellabile per timer, animazioni e impulsi SVG;
- formalizzata la sequenza con stato iniziale `off` escluso dal ciclo;
- introdotti lifecycle viewport/documento e autoplay opzionale;
- aggiunti contratto concettuale, esempio minimo e matrice di collaudo;
- aggiunta la verifica automatica `verify:schemi` alla build;
- mantenuti invariati markup, CSS e JavaScript dei quattro schemi esistenti.
